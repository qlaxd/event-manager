The UCC Event Manager is a secure, multi-user event management system designed to allow users to create, view, update, and delete their personal events.

Key Features:
- User Authentication: Secure login with email/password, optional MFA, and password reset.
- Event Management: Users can create events with a title, occurrence, and description. They can view, update, and delete their own events.
- Helpdesk Chatbot: Users can ask free-form questions to get automated answers. The chatbot can escalate to a human agent.
- Voice Helpdesk: A bonus feature allowing users to interact with the helpdesk via voice.
- Security: The application follows best practices, including protection against OWASP Top 10 risks.

How to create an event:
To create a new event, a user must be logged in. From the dashboard, they can click "Add Event" and fill in the required fields: a title and an occurrence date/time. A description is optional.

How to edit an event:
To edit an event, a user can find the event in their list on the dashboard and click the edit icon. Only the description of an event can be updated after it has been created.

How to delete an event:
To delete an event, a user can find it in their list on the dashboard and click the delete icon. The user will be asked to confirm before the event is permanently removed.
